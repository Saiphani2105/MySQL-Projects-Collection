# 📂 MySQL Projects Collection

A collection of SQL database implementations for **Library Management, E-Commerce, and Netflix Content Analysis**. Each project contains structured queries and database schemas to solve real-world data challenges.

---

## 📌 Projects

### 📚 1. Library Management (`library.sql`)
A database for tracking books, borrowers, and loans across library branches.

#### 🔍 Key Queries:
- **JOIN operations** to find specific book copies at branches
- **LEFT JOIN** to identify inactive borrowers
- **CTEs** for loan tracking with due dates
- **Subqueries** for author-specific inventory
- **GROUP BY** for branch-wise loan statistics
- **HAVING** clause for high-volume borrower identification

---

### 🛒 2. E-Commerce (`E-Commerce_Assignment.sql`)
A customer order processing system with product catalog and tracking.

#### 🔍 Key Queries:
- **JOIN & GROUP BY** for customer order counts
- **Aggregate functions** for revenue calculation
- **Subqueries** for above-average customer identification
- **LEFT JOIN** to find non-selling products
- **Multiple JOINs** for customer purchase patterns

---

### 🎬 3. Netflix Content Analysis (`NETFLIX_Assignment.sql`)
A database for analyzing Netflix shows and movies.

#### 🔍 Key Queries:
- **GROUP BY** for content type distribution
- **ORDER BY with string functions** for duration analysis
- **Conditional aggregation** for director statistics
- **Multiple filtering conditions** for specific content tracking
